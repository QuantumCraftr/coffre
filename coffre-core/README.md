# coffre-core

Coeur du coffre de secrets `coffre` : format de fichier chiffré, dérivation de clé
(Argon2id), AEAD XChaCha20-Poly1305, écriture atomique et zeroization.

Cette bibliothèque est utilisée par le binaire [`coffre`](https://github.com/QuantumCraftr/coffre).

- Projet complet, threat model et format : https://github.com/QuantumCraftr/coffre
- Documentation : https://docs.rs/coffre-core
